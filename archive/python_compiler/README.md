# Archived Python compiler

This directory preserves the former Atlas Python compiler, its compatibility facade, integration
helpers, documentation, and focused tests as reference material for the future C compiler.

It is intentionally outside the Python project rooted at `backend/`. Nothing here is packaged,
imported, initialized, tested, or supported by the active Atlas application. The archive must not
constrain the `ingest.*` or `material.*` contracts. See `docs_v2/CUTOFF.md`.
