# Vision

Periplus gives you the power to query the web through SQL.

Search finds pages where somebody wrote an answer. Periplus lets you derive an answer from the
websites you have observed.

Periplus acquires web content, preserves its source evidence, and turns observations, immutable
bytes, HTML structure, and observed links into queryable relations.

Periplus owns the path from the web to reliable evidence primitives. It does not define products,
companies, topics, claims, people, or other domain concepts. Interpretation begins in the user's
own database, notebook, agent, or application.

The result is a programmable web corpus:

```text
web observations -> immutable content -> queryable evidence
```

The stable SQL contract is defined in [`SCHEMA.md`](SCHEMA.md). Periplus can add evidence primitives
after their grain and semantics are proven without turning downstream interpretation into a Periplus
responsibility.
